Conecte a sua Cube Baby

Ligue a pedaleira no USB do computador e clique em Conectar. O programa procura a pedaleira automaticamente em todas as portas MIDI.

    Gire os knobs com o mouse (arraste para cima/baixo), a roda do mouse ou as setas do teclado. Cada mudança é enviada na hora para a pedaleira.

    IRs de fábrica

    Regrava os 8 IRs originais usando o arquivo BFI.bin que vem na pasta bin/ do CubeSuite para Windows.

    USB Loopback

    Quando ligado, o áudio que sai do computador pelo USB também é tocado na saída de fone da pedaleira (útil para tocar junto com músicas).
