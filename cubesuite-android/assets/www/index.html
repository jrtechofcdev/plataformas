Conecte a Cube Baby

Ligue a pedaleira no celular com um cabo USB + adaptador OTG. O app encontra a pedaleira sozinho.

  • Use um adaptador OTG (USB-C ou micro-USB) que passe dados, não só carga.
  • Se o Android perguntar qual app abrir para o aparelho USB, escolha Cube Remote.
  • Feche outros apps de música/MIDI que possam estar usando a pedaleira.
  • Se pedir permissão USB, toque em Permitir.
  • Não conectou? Abra o 📋 Log e toque em Compartilhar para enviar os detalhes.

Esta Cube Baby é da geração antiga: ela não tem presets editáveis pelo USB. Use a aba IR para trocar os IRs.
